# vlue-media

Archivo público de imágenes de Vlue Tech Services para redes sociales, catálogo y ficha de Google.
Sigue la misma estructura que la carpeta "Redes sociales" de Drive.

| Carpeta | Contenido |
|---|---|
| `catalogo-imgs/` | Imágenes de cada servicio del catálogo, una carpeta por servicio |
| `catalogo-imgs/sesion-estrategica-1-1/` | Sesión estratégica 1:1: carrusel (`ig_`), WhatsApp, Google e historia, en PNG; copias en `jpg/` |
| `catalogo-imgs/tarjeta-vlue/` | Tarjeta Vlue individual: carrusel (`ig_`, 1080×1440), `cuadrado_` (1080×1080, TikTok y WhatsApp), Google e historia; copias en `jpg/` |
| `catalogo-imgs/trio-vlue/` | Trío de Tarjetas Vlue: mismos formatos que la Tarjeta Vlue |
| `updates-y-relatos/` | Novedades de Google (1200×900) y posts tipo relato o consejo para LinkedIn (1080×1350), una carpeta por tema; copias en `jpg/` |
| `updates-y-relatos/pedir-resenas/` | "Pedir reseñas también es escuchar": novedad de Google y post de LinkedIn |
| `posts/` | Carruseles y posts de redes, una carpeta por tema |
| `posts/web-funciona/` | "Tu web no necesita ser cara. Necesita funcionar.": carrusel Instagram (`ig_`, 1080×1440) y TikTok (`tt_`, 1080×1080); copias en `jpg/` |
| `elementos-visuales/` | Elementos 3D sueltos con fondo transparente (celular, pin, reseña, búsqueda, insignia, tarjetas de reseña, wifi y redes, trío de tarjetas, notebook, celular con web de clínica, botón Agendar hora, reloj de pared) |
| `elementos-visuales/hojas-de-referencia/` | Hojas con todos los elementos a la vista |
| `elementos-visuales/marca/logos/` | Símbolo de Vlue y logos con dominio y con Instagram, en cuatro colores |
| `elementos-visuales/marca/contacto/` | Bloques y franjas de contacto (WhatsApp, Instagram, web) |
| `elementos-visuales/marca/iconos/` | Íconos de redes en azul y blanco |

Los nombres van sin tildes, espacios ni dos puntos para que los enlaces funcionen en cualquier herramienta.
Este repositorio es público: no guardar aquí material interno ni datos de clientes.
